## O que muda

- `test/e2e/run.mjs` (`npm run e2e`): carrega a extensão num Chromium e roda 17 passos — página de teste com CSS de outra origem sem CORS, tema escuro, sprite SVG, `element.animate()`, reveal por IntersectionObserver, Lottie, srcset sem espaço e `:hover` em classe escapada; todas as abas; kit conferido com `unzip`; pinça com `::before`, hover de ancestral e **↑ Pai**; Figma simulado (API, estilos, variáveis, protótipo, Motion, seleção → código, kit com frames/ícones/imagens/vídeo) e o aviso de API inativa.
- `test/e2e/real-sites.mjs`: fumaça em sites reais (precisa de internet), imprime o resumo de cada extração.
- Job `e2e` no CI.

## Por quê

Os testes unitários cobrem `lib/`; o que só existe no navegador (content scripts, service worker, painel, downloads) precisa de um navegador de verdade.

## Como testar

`npx playwright install chromium` e `npm run e2e` — 17/17 passos.
